# Java Week 1 Assignment

## Overview
This repository contains the Library Management System developed as part of the Java Week 1 assignment.

## Objective
To demonstrate Java fundamentals, object-oriented programming, collections, input validation, exception handling, and file handling.

## Project Structure
- `library_management_system/` – Library Management System project
- `library_management_system/src/` – Java source files
- `library_management_system/data/` – Application data files
- `library_management_system/README.md` – Project documentation
- `screenshots/` – Application testing screenshots

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- File Handling
- Exception Handling

## How to Run
1. Install a compatible Java Development Kit (JDK).
2. Open the `library_management_system` folder.
3. Follow the compile and run instructions in its `README.md`.
4. Execute the application and test its features.

## Testing Evidence
The `screenshots/` folder contains screenshots of login, book management, student management, book issue and return, and history operations.
